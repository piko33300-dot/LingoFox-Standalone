# دليل النشر الكامل — LingoFox 🦊

هذا الدليل يجمع كل الخطوات من البداية حتى يصبح التطبيق متاحاً على الإنترنت وGoogle Play وApp Store.
التفاصيل الدقيقة لكل متجر موجودة في `ANDROID-BUILD-ar.md` و`IOS-BUILD-ar.md`.

---

## ما الجديد في هذه النسخة

| الميزة | أين تجدها |
|---|---|
| 6 دورات: الإنجليزية، العربية (للناطقين بالإنجليزية)، الإسبانية، الفرنسية، التركية، الألمانية | صفحة الدورات |
| «اسأل فوكس» داخل كل درس: شرح مخصّص لسبب صحة أو خطأ إجابتك، وتصحيح أي إجابة تكتبها بنفسك | زر «اسأل فوكس» بعد التحقق من الإجابة |
| المعلّم الذكي «فوكس»: محادثة حقيقية بلغة الدورة مع تصحيح الأخطاء بالعربية، تُحفظ في الحساب | زر «المعلّم» في الشريط السفلي |
| تدريب النطق: تقول الجملة بصوتك، والذكاء الاصطناعي يقيّمها كلمة بكلمة | بطاقة «تدرّب على النطق» في صفحة التعلّم |
| الدوريات الأسبوعية (برونزي ← ماسي): أفضل 10 يصعدون وآخر 5 ينزلون كل يوم اثنين تلقائياً | صفحة المتصدرين ← الدوري |
| الأصدقاء: رمز صداقة من 6 أحرف ومنافسة أسبوعية بينكم | صفحة المتصدرين ← الأصدقاء |
| تذكير يومي الساعة 8 مساءً (داخل تطبيق الهاتف فقط) | صفحة حسابي |

حدود الاستخدام اليومية لكل مستخدم (لحماية تكلفة الذكاء الاصطناعي): 40 رسالة للمعلّم، 60 شرحاً من «اسأل فوكس»، و60 محاولة نطق.

## 1) انشر الموقع (أهم خطوة — كل شيء يعتمد عليها)

1. جهّز قاعدة البيانات والمفاتيح كما في `STANDALONE-ar.md`.
2. ابنِ وشغّل الخادم على استضافتك (VPS أو Vercel أو Netlify أو Cloudflare) — التفاصيل في `STANDALONE-ar.md`.
3. اربط نطاقك الخاص (مثل `https://lingofox.app`) مع شهادة HTTPS.

> تطبيقا Android وiPhone يفتحان هذا الرابط. أي تحديث تنشره للموقع يصل لمستخدمي التطبيقين فوراً بدون رفع نسخة جديدة للمتجر.

## 2) ضع الرابط داخل تطبيقات الهاتف

افتح الملف `capacitor-www/app-url.js` وغيّر السطر إلى رابطك:

```js
window.LINGOFOX_APP_URL = "https://رابطك-المنشور";
```

ثم من مجلد المشروع:

```bash
npm install
npx cap sync
```

## 3) ارفع الكود إلى GitHub (للحفظ والنشر التلقائي)

```bash
git init && git add . && git commit -m "LingoFox"
git remote add origin https://github.com/حسابك/lingofox.git
git push -u origin main
```

التفاصيل في `GITHUB-SETUP-ar.md`. ملف `.env` لا يُرفع أبداً.

## 4) الذكاء الاصطناعي

المعلّم و«اسأل فوكس» وتقييم النطق تعمل بمفتاح Google Gemini الخاص بك (`GEMINI_API_KEY`) على الخادم فقط.
التكلفة تُحسب على حسابك في Google، والحدود اليومية لكل متعلّم تحميك من الاستخدام المفرط.

## 5) Google Play

اتبع `ANDROID-BUILD-ar.md` خطوة بخطوة. باختصار:
1. ثبّت Android Studio.
2. `npx cap sync android` ثم `npx cap open android`.
3. أنشئ مفتاح التوقيع (احتفظ به للأبد — بدونه لا يمكن تحديث التطبيق).
4. ابنِ ملف **AAB** وارفعه في Google Play Console (رسوم التسجيل 25 دولاراً مرة واحدة).

صلاحيات Android المضافة: الإنترنت، الميكروفون (لتدريب النطق)، الإشعارات (للتذكير اليومي).

## 6) App Store

اتبع `IOS-BUILD-ar.md`. باختصار:
1. تحتاج جهاز Mac عليه Xcode، وحساب Apple Developer (99 دولاراً سنوياً).
2. `npx cap sync ios` ثم `npx cap open ios`.
3. اختر فريقك في **Signing & Capabilities**، ثم **Product ← Archive ← Distribute App**.

وصف استخدام الميكروفون مضاف مسبقاً (تطلبه Apple عند المراجعة).

## 7) قبل الإرسال للمراجعة — قائمة تحقق

- [ ] الموقع منشور والرابط مضبوط في `capacitor-www/app-url.js`.
- [ ] رابط سياسة الخصوصية: `https://رابطك/privacy` (مطلوب في المتجرين).
- [ ] ضع بريد التواصل في `src/lib/legal.ts` (`CONTACT_EMAIL`).
- [ ] حذف الحساب يعمل من صفحة «حسابي» (Apple وGoogle تطلبانه).
- [ ] لقطات شاشة للهاتف (6.7 بوصة لـ iPhone، و2–8 لقطات لـ Android).
- [ ] أيقونة 512×512 لـ Google (موجودة: `public/icon-512.png`)، و1024×1024 لـ Apple (موجودة داخل مشروع Xcode في `ios/App/App/Assets.xcassets`).
- [ ] في نموذج «أمان البيانات» في Google Play اذكر: البريد الإلكتروني، تقدّم التعلم، تسجيلات صوتية تُرسل للتقييم ولا تُخزَّن.

## 8) الإعلانات

- على الموقع: ضع معرّفات AdSense في `src/lib/ads-config.ts` بعد موافقة Google على موقعك المنشور.
- داخل تطبيقات الهاتف: الإعلانات تحتاج AdMob (معرّفات منفصلة) — أرسلها لي عندما تحصل عليها.

## 9) التحديثات لاحقاً

- **تغيير الدروس أو الشكل أو الميزات:** عدّل الكود ثم أعد البناء والنشر على استضافتك — يصل للجميع فوراً.
- **تغيير الأيقونة أو الاسم أو الصلاحيات:** يتطلب بناء نسخة جديدة ورفعها للمتجر.

## 10) التشغيل على حاسوبك

```bash
bun install
bun run dev        # http://localhost:8080
bun run test       # الاختبارات
```
