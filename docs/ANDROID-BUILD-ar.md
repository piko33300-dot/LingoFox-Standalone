# دليل بناء نسخة Android ونشرها في Google Play — LingoFox

هذا الدليل يشرح خطوة بخطوة كيف تحوّل ملفات المشروع إلى تطبيق Android جاهز للرفع إلى متجر Google Play، وكيف توقّعه وتجرّبه على هاتفك.

---

## ما الذي جُهّز مسبقاً في المشروع

| الملف / المجلد | الغرض |
| --- | --- |
| `android/` | مشروع Android كامل يُفتح مباشرة في Android Studio |
| `capacitor.config.ts` | إعدادات التطبيق: الاسم **LingoFox** ومعرّف الحزمة **com.lingofox.app** |
| `capacitor-www/app-url.js` | **المكان الوحيد** الذي تضع فيه رابط موقعك المنشور |
| `capacitor-www/offline.html` | شاشة «لا يوجد اتصال بالإنترنت» مع زر «حاول مرة أخرى» |
| `android/keystore.properties.example` | نموذج لبيانات مفتاح التوقيع |
| `assets/` | الصور الأصلية للأيقونة وشاشة البداية (الثعلب) |

**ما يفعله التطبيق:** يفتح موقع LingoFox المنشور داخل تطبيق Android حقيقي بأيقونته واسمه وشاشة بدايته. أي تحديث تنشره للموقع يصل فوراً لكل مستخدمي التطبيق **دون** رفع نسخة جديدة إلى المتجر.

**تعديلات تلقائية داخل التطبيق فقط (لا تؤثر على الموقع):**
- زر الرجوع في الهاتف يرجع للشاشة السابقة، ومن الشاشة الأولى يغلق التطبيق.
- يُخفى زر «المتابعة باستخدام Google» لأن Google تمنع تسجيل الدخول داخل التطبيقات بهذه الطريقة. المستخدم يسجّل بالبريد وكلمة المرور، وحسابه وتقدّمه نفسهما في الموقع والتطبيق.
- تُخفى إعلانات AdSense لأنها **ممنوعة داخل تطبيقات المتجر** (انظر قسم الإعلانات).
- تُخفى بطاقة «ثبّت التطبيق» لأنه مثبّت أصلاً.

---

## 1) المتطلبات على حاسوبك

يعمل على Windows أو Mac أو Linux:

1. **Node.js الإصدار 22 أو أحدث** — من https://nodejs.org (اختر LTS).
2. **Android Studio** (أحدث إصدار) — من https://developer.android.com/studio
   - عند أول تشغيل اختر **Standard** ليُنزّل Android SDK تلقائياً.
   - Android Studio يحتوي على Java 21 المطلوبة، فلا تحتاج تثبيتها وحدك.
3. فكّ الملف المضغوط في مجلد على حاسوبك، مثلاً `C:\lingofox` أو `~/lingofox`.

---

## 2) انشر الموقع وضع رابطه

1. انشر موقعك على استضافتك (انظر `STANDALONE-ar.md`) وانسخ الرابط، مثل `https://lingofox.app`.
2. افتح الملف `capacitor-www/app-url.js` بأي محرر نصوص وغيّر السطر إلى رابطك:

```js
window.LINGOFOX_APP_URL = "https://lingofox.app";
```

> لو ربطت لاحقاً نطاقاً خاصاً (مثل `lingofox.com`) ضع النطاق هنا وأعد الخطوة 3.

---

## 3) تجهيز المشروع (مرة واحدة، ثم بعد أي تغيير في الإعدادات)

افتح الطرفية (Terminal، أو PowerShell في Windows) داخل مجلد المشروع ونفّذ:

```bash
npm install
npx cap sync android
```

- الأمر الأول يُنزّل المكتبات.
- الأمر الثاني ينسخ الإعدادات والرابط إلى مشروع Android.

---

## 4) جرّب التطبيق على هاتفك قبل النشر

**على الهاتف:**
1. الإعدادات ← حول الهاتف ← اضغط **رقم الإصدار (Build number)** سبع مرات لتفعيل «خيارات المطوّر».
2. الإعدادات ← النظام ← خيارات المطوّر ← فعّل **تصحيح USB (USB debugging)**.
3. صِل الهاتف بالحاسوب بسلك USB ووافق على رسالة «السماح بتصحيح USB».

**على الحاسوب:**

```bash
npx cap open android
```

يفتح Android Studio. انتظر حتى ينتهي شريط **Gradle Sync** في الأسفل (أول مرة قد تستغرق عدة دقائق)، ثم اختر هاتفك من القائمة في الأعلى واضغط زر التشغيل ▶️.

> بديل بدون هاتف: في Android Studio افتح **Device Manager** وأنشئ هاتفاً افتراضياً (Emulator).

**ماذا تجرّب:** فتح التطبيق، شاشة البداية بالثعلب، إكمال درس، إنشاء حساب بالبريد، زر الرجوع، وإطفاء الإنترنت لرؤية شاشة «لا يوجد اتصال».

---

## 5) إنشاء مفتاح التوقيع (مرة واحدة فقط في حياة التطبيق)

Google Play يتطلب أن يكون الملف موقّعاً بمفتاح خاص بك ("مفتاح الرفع").

### الطريقة الأسهل — من داخل Android Studio
1. القائمة **Build ← Generate Signed App Bundle / APK**.
2. اختر **Android App Bundle** ← Next.
3. تحت *Key store path* اضغط **Create new…** واملأ:
   - **Key store path:** داخل مجلد `android` باسم `lingofox-upload.jks`
   - **Password:** كلمة مرور قوية (احفظها!)
   - **Alias:** `lingofox`
   - **Validity:** 25 سنة أو أكثر
   - **First and Last Name / Organization / Country:** بياناتك (مثلاً Country Code: `YE`)
4. أكمل باختيار **release** ثم **Create**.

### أو من الطرفية

```bash
cd android
keytool -genkeypair -v -keystore lingofox-upload.jks -alias lingofox -keyalg RSA -keysize 2048 -validity 10000
```

> إن لم يُعرف الأمر `keytool`، فهو موجود داخل Android Studio في المجلد `jbr/bin`.

### اربط المفتاح بالمشروع
1. انسخ `android/keystore.properties.example` إلى ملف جديد باسم `android/keystore.properties`.
2. ضع فيه كلمات المرور الحقيقية:

```properties
storeFile=lingofox-upload.jks
storePassword=كلمة_مرور_المخزن
keyAlias=lingofox
keyPassword=كلمة_مرور_المفتاح
```

### ⚠️ مهم جداً
- **احتفظ بنسخة احتياطية** من `lingofox-upload.jks` و`keystore.properties` في مكانين آمنين (مثل فلاشة + خدمة تخزين خاصة).
- **لا ترسلهما لأحد ولا ترفعهما لأي موقع.**
- إن فقدت مفتاح الرفع يمكن طلب استبداله من Google Play (لأن Google تحتفظ بمفتاح التوقيع النهائي)، لكنه إجراء يأخذ وقتاً.

## 6) بناء ملف المتجر (AAB)

من الطرفية:

```bash
cd android
./gradlew bundleRelease        # على Mac / Linux
gradlew.bat bundleRelease      # على Windows
```

أو من Android Studio: **Build ← Generate Signed App Bundle / APK** واختر المفتاح الذي أنشأته.

الملف الناتج:

```
android/app/build/outputs/bundle/release/app-release.aab
```

هذا هو الملف الذي تُرفعه إلى Google Play.

> **لكل رفع جديد** إلى المتجر: افتح `android/app/build.gradle` وزِد `versionCode` بمقدار 1 (1 ← 2 ← 3 …) وغيّر `versionName` إن أردت (مثل `1.0.1`). المتجر يرفض ملفاً بنفس رقم `versionCode` السابق.

---

## 7) النشر في Google Play Console

1. **أنشئ حساب مطوّر:** https://play.google.com/console — رسوم **25 دولاراً مرة واحدة** + التحقق من الهوية (بطاقة/جواز). اختر حساباً **شخصياً** أو **مؤسسة**.
2. **Create app:** الاسم `LingoFox`، اللغة الافتراضية العربية، النوع **App**، **Free**.
3. **Play App Signing:** اتركه مفعّلاً (الخيار الافتراضي) — Google تحفظ مفتاح التوقيع النهائي.
4. **ارفع الملف:** Testing ← **Internal testing** ← Create release ← ارفع `app-release.aab`. أضف بريدك كمختبِر وجرّبه من المتجر على هاتفك.
5. **شرط الحسابات الشخصية الجديدة:** قبل النشر العام يجب تشغيل **Closed testing** مع **12 مختبِراً على الأقل لمدة 14 يوماً متتالية**. اطلب من أصدقاء أو عائلة الانضمام عبر رابط الاختبار. (حسابات المؤسسات معفاة.)
6. **أكمل قسم App content (إلزامي):**
   - **Privacy policy:** رابط صفحة سياسة الخصوصية (مطلوب لأن التطبيق فيه حسابات وإعلانات).
   - **App access:** وضّح أن الدروس متاحة دون تسجيل، وأعطِ حساب تجربة إن طُلب.
   - **Ads:** «نعم، يحتوي إعلانات» إذا أضفت AdMob.
   - **Content rating:** املأ الاستبيان (تعليمي).
   - **Target audience:** إن اخترت أعماراً تحت 13 سنة تنطبق سياسة **Families** الصارمة على الإعلانات والبيانات — الأسهل اختيار 13 سنة فأكثر.
   - **Data safety:** التطبيق يجمع البريد الإلكتروني والاسم (للحساب) وتقدّم التعلّم، وكلها مشفّرة أثناء النقل، والمستخدم يستطيع طلب حذفها.
   - **حذف الحساب:** Google تطلب رابطاً أو طريقة لحذف الحساب — اطلبها مني لأضيف زر «حذف حسابي».
7. **Store listing:**
   - أيقونة 512×512 — موجودة في `public/icon-512.png`
   - صورة الغلاف (Feature graphic) 1024×500
   - صورتان على الأقل من شاشات الهاتف (التقطها من التطبيق أثناء التجربة)
   - وصف قصير (80 حرفاً) ووصف كامل
8. **Production ← Create release** ← ارفع الملف ← **Send for review**. المراجعة عادة من يوم إلى 7 أيام.

## 8) الإعلانات داخل تطبيق Android

- إعلانات **AdSense** مخصّصة للمواقع فقط، وسياستها تمنع عرضها داخل التطبيقات؛ لذلك أُخفيت تلقائياً داخل التطبيق وتبقى ظاهرة في الموقع.
- للربح من التطبيق استخدم **Google AdMob** (https://admob.google.com): أنشئ حساباً، أضف التطبيق، واحصل على App ID ومعرّفات الوحدات (بانر + مكافأة)، ثم أرسلها لي لأجهّز ربطها.

## 10) حلول المشكلات الشائعة

| المشكلة | الحل |
| --- | --- |
| التطبيق يفتح على شاشة «لا يوجد اتصال» دائماً | تأكد من الرابط في `capacitor-www/app-url.js` ثم `npx cap sync android` |
| خطأ `Unsupported class file major version` أو مشكلة Java | Android Studio ← Settings ← Build Tools ← Gradle ← **Gradle JDK** = jbr-21 |
| `SDK location not found` | افتح مجلد `android` مرة في Android Studio ليُنشئ `local.properties` تلقائياً |
| `node: command not found` أو خطأ في إصدار Node | ثبّت Node.js 22 أو أحدث وأعد فتح الطرفية |
| Google Play يرفض: "Version code already used" | زِد `versionCode` في `android/app/build.gradle` |
| رسالة تأكيد البريد أو استعادة كلمة المرور تفتح المتصفح | طبيعي — بعد التأكيد ارجع للتطبيق وسجّل الدخول |

## ملاحظات

- **معرّف الحزمة `com.lingofox.app` دائم** بعد أول رفع للمتجر ولا يمكن تغييره. إن أردت معرّفاً آخر (مثل `com.alimohammad.lingofox`) غيّره قبل أول رفع في `capacitor.config.ts` و`android/app/build.gradle` (السطرين `namespace` و`applicationId`) ثم أخبرني لأتأكد من الباقي.
