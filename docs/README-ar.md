# LingoFox 🦊 — تعلّم اللغات مع ثعلب ذكي

## التشغيل محلياً
```sh
cp .env.example .env   # ضع مفاتيحك (انظر STANDALONE-ar.md)
bun install            # تثبيت الحزم (مرة واحدة)
bun run dev            # تشغيل خادم التطوير
```
ثم افتح العنوان الذي يظهر في الطرفية.

> هذه النسخة مستقلة: الحسابات والحفظ في مشروع Supabase الخاص بك، والذكاء الاصطناعي من Google Gemini. خطوات الإعداد في `STANDALONE-ar.md`.

## الميزات
- واجهة عربية كاملة (من اليمين لليسار) مع زر للتبديل إلى الإنجليزية
- 6 دورات: الإنجليزية والعربية والإسبانية والفرنسية والتركية والألمانية، مع قصص قصيرة تفاعلية
- «اسأل فوكس» داخل كل درس: شرح وتصحيح مخصّص بالذكاء الاصطناعي، ومعلّم محادثة، وتقييم للنطق
- دوريات أسبوعية وأصدقاء وتذكير يومي
- 5 أنواع أسئلة: اختيار بالصور، استماع بالنطق الصوتي (مع زر البطء)، كتابة، مطابقة أزواج، بناء جمل
- السؤال الخاطئ يعود في نهاية الدرس، ومكافأة +5 نقاط للدرس المثالي
- حسابات: بريد وكلمة مرور و Google — مع استعادة كلمة المرور
- حفظ التقدم في السحابة على كل الأجهزة (ويُدمج تقدّم الضيف عند تسجيل الدخول)
- لوحة المتصدرين، صفحة الحساب والإحصائيات، 12 إنجازاً، هدف يومي قابل للتعديل، وتقويم التتابع
- وضع «تدرّب وراجع»: مراجعة متباعدة للكلمات التي أخطأت فيها
- صفحة سياسة الخصوصية وزر حذف الحساب (مطلوبان في Google Play)
- القلوب والجواهر، وإعادة التعبئة بالجواهر أو بمشاهدة إعلان (حتى 5 مرات يومياً)

## الربح من الإعلانات (Google AdSense)
1. انشر التطبيق على رابط عام ثم سجّل في https://adsense.google.com وانتظر الموافقة.
2. أنشئ 3 وحدات إعلانية (Display) وانسخ أرقامها.
3. افتح `src/lib/ads-config.ts` وضع رقم الناشر `ca-pub-...` في `client` وأرقام الوحدات في `slots`.
4. أنشئ الملف `public/ads.txt` بالمحتوى: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
حتى ذلك الحين تظهر "مساحة إعلانية" مكان الإعلانات.

## ملفات مهمة
